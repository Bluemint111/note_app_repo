# Note Taking App 3.0

This project contains:

- `client/` - React front-end styled like a notes app with spreadsheet-style notes.
- `server/` - Node.js back-end with Supabase integration for notes storage.
- `export/` - Node.js export service to generate Excel files.

## Setup

1. Install Node.js.
2. From `client/`: `npm install`.
3. From `server/`: `npm install`.
4. From `export/`: `npm install`.

## Run

- Front-end: `cd client && npm start`
- Back-end: `cd server && npm start`
- Export service: `cd export && npm start`
